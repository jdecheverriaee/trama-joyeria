# trama. | Catálogo web

Sitio estático (HTML + CSS), sin build.

## Subir a GitHub y Vercel
1. Crea un repositorio en GitHub y sube **el contenido de esta carpeta** (index.html, style.css, assets/, etc.).
2. En vercel.com: Add New > Project > importa el repositorio.
3. Framework Preset: **Other**. Deja vacíos Build Command y Output Directory. Deploy.

## Editar
- Precios, nombres y textos: en `index.html`.
- Fotos: carpeta `assets/img/` (formato 4:5, 800x1000).
